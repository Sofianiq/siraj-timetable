# نظام إدارة الجداول الدراسية – جامعة السراج - كلية التقنيات الصحية والطبية

نظام ويب عربي متكامل لإعداد الجداول الأسبوعية لكل أقسام الكلية. يكشف التعارضات ويمنعها فوراً، ويولّد الجداول تلقائياً، ويسمح بالعمل التشاركي مع مزامنة فورية بين الأجهزة.

## المزايا
- **البيانات الأساسية**: الكليات، والأقسام، والمراحل، والشعب (صباحي/مسائي، مع تقسيم المرحلة إلى مجموعات)، والأساتذة وأوقات توفرهم، والقاعات والمختبرات، والمواد بساعاتها النظرية والعملية. مع **استيراد المناهج من Excel**.
- **منع التعارضات فوراً**:
  - الأستاذ لا يُسند لمحاضرتين في الوقت نفسه.
  - القاعة أو المختبر لا يُحجز مرتين، **على مستوى الجامعة**، مع دعم حجوزات الكليات الأخرى.
  - محاضرات الشعبة لا تتداخل.
  - تنبيه عند تجاوز سعة القاعة، أو الوقت خارج توفر الأستاذ، أو خارج الدوام.
- **توليد تلقائي ذكي** يراعي كل القيود، مع إمكانية التعديل اليدوي وتثبيت المحاضرات.
- **سحب وإفلات** بالفأرة واللمس، و**تعديل حر للوقت** بالدقيقة.
- **العرض** حسب: المرحلة والشعبة، أو القسم، أو الأستاذ، أو القاعة/المختبر. مع عرض قائمة للهاتف.
- **تصدير احترافي** إلى PDF وExcel وطباعة مباشرة، بترويسة تضم الجامعة والكلية والقسم والمرحلة ونوع الدراسة والفصل.
- **العمل التشاركي** مع مزامنة فورية، و**صلاحيات**: معاون عميد، ومسؤول قسم، وعرض فقط. مع **رابط عام للطلبة** يتحدّث تلقائياً.
- **نسخ احتياطي** واستعادة، ونسخ جداول فصل سابق.
- واجهة عربية كاملة (RTL)، متجاوبة مع الحاسوب واللوحي والهاتف، وتدعم الوضع الداكن.

## البدء السريع
- **للتجربة فوراً:** شغّل خادماً محلياً (`npm start`) وافتح `http://localhost:8080`. يعمل النظام في الوضع التجريبي المحلي، ويُدرج بيانات قسم الأشعة تلقائياً.
- **للنشر الفعلي:** اتبع [دليل النشر خطوة بخطوة](docs/DEPLOYMENT_GUIDE.md): رفع الملفات على GitHub Pages، وإنشاء Firebase، ثم تعديل `js/config.js`.

## البيانات الأولية لقسم تقنيات الأشعة والسونار
تُدرج تلقائياً عند أول تشغيل. مصدرها كشوف درجات القسم للعام 2025-2026، وتشمل:

- **الفصل الثاني – المرحلة الأولى:** علم الفسلجة، وتشريح أجهزة الجسم، وفيزياء الذرة، والبايولوجي الإشعاعي، وأسس التمريض، واللغة العربية، والمصطلحات الطبية.
- **الفصل الثاني – المرحلة الثانية:** التشريح الشعاعي للرأس والأطراف العليا، وتقنيات التصوير الشعاعي للأطراف العليا، وفحوصات شعاعية للجهاز الصفراوي والتناسلي، وتقنيات الأجهزة الشعاعية التقليدية، وفيزياء التصوير المحوسب، واللغة العربية.

> ساعات هذه المواد قيم افتراضية معلَّمة بـ«مراجعة». لإدراج المنهج الرسمي الكامل لكل المراحل استخدم **المواد الدراسية ← استيراد المناهج من Excel** (يتوفر نموذج جاهز للتنزيل).
