# نظام إدارة الجداول الدراسية – جامعة السراج

نظام ويب عربي متكامل لإعداد الجداول الأسبوعية لكليات الجامعة وأقسامها: كلية التقنيات الصحية والطبية، وكلية الصيدلة، وكلية طب الأسنان، مع إمكانية إضافة كليات أخرى. يكشف التعارضات ويمنعها فوراً، ويولّد الجداول تلقائياً، ويسمح بالعمل التشاركي مع مزامنة فورية بين الأجهزة.

## المزايا
- **عدة كليات**: اختيار الكلية من الشريط العلوي. لكل كلية كادرها التدريسي مع دعم الأساتذة المشتركين بين الكليات (دون تكرار ودون تعارض)، والقاعات والمختبرات مشتركة، والمواد خاصة بكل قسم/كلية.
- **البيانات الأساسية**: الكليات، والأقسام، والمراحل، والشعب (صباحي/مسائي، مع تقسيم المرحلة إلى مجموعات)، والأساتذة وأوقات توفرهم، والقاعات والمختبرات، والمواد بساعاتها النظرية والعملية. مع **استيراد المناهج من Excel**.
- **المناهج الرسمية مُدرجة**: كل مواد أقسام كلية التقنيات الصحية والطبية لكل المراحل والفصول، مقسّمة إلى نظري وعملي حسب الخطة الرسمية، مع أسماء الكادر التدريسي دون تكرار.
- **منع التعارضات فوراً**:
  - الأستاذ لا يُسند لمحاضرتين في الوقت نفسه.
  - القاعة أو المختبر لا يُحجز مرتين، **على مستوى الجامعة**، مع دعم حجوزات الكليات الأخرى.
  - محاضرات الشعبة لا تتداخل.
  - تنبيه عند تجاوز سعة القاعة، أو الوقت خارج توفر الأستاذ، أو خارج الدوام.
- **توليد تلقائي ذكي** يراعي كل القيود، مع إمكانية التعديل اليدوي وتثبيت المحاضرات.
- **سحب وإفلات** بالفأرة واللمس، و**تعديل حر للوقت** بالدقيقة.
- **العرض** حسب: المرحلة والشعبة، أو القسم، أو الأستاذ، أو القاعة/المختبر. مع عرض قائمة للهاتف.
- **تصدير احترافي** إلى PDF وExcel وطباعة مباشرة، بترويسة تضم شعار الكلية والجامعة وكلية الجدول والقسم والمرحلة ونوع الدراسة والفصل، ودليل ألوان ومكان توقيع. الدوام الافتراضي من 8:30 إلى 2:30.
- **العمل التشاركي** مع مزامنة فورية، و**صلاحيات**: مدير النظام، ومعاون عميد لكل كلية، ومسؤول قسم، وعرض فقط. مع **رابط عام للطلبة** يتحدّث تلقائياً.
- **نسخ احتياطي** واستعادة، ونسخ جداول فصل سابق.
- واجهة عربية كاملة (RTL)، متجاوبة مع الحاسوب واللوحي والهاتف، وتدعم الوضع الداكن.

## البدء السريع
- **للتجربة فوراً:** شغّل خادماً محلياً (`npm start`) وافتح `http://localhost:8080`. يعمل النظام في الوضع التجريبي المحلي، ويُدرج بيانات قسم الأشعة تلقائياً.
- **للنشر الفعلي:** اتبع [دليل النشر خطوة بخطوة](docs/DEPLOYMENT_GUIDE.md): رفع الملفات على GitHub Pages، وإنشاء Firebase، ثم تعديل `js/config.js`.
- **قاعدة البيانات Supabase بدلاً من Firebase:** اتبع [دليل Supabase](docs/SUPABASE_GUIDE.md)، وفيه نقل البيانات الحالية بضغطة زر.

## المناهج الرسمية لكلية التقنيات الصحية والطبية
تُدرج تلقائياً عند أول تشغيل (وعند الترقية للأنظمة القائمة)، ويمكن إعادة استيرادها من **الإعدادات ← 📚 استيراد المناهج الرسمية والكادر**:

| القسم | المصدر |
|---|---|
| تقنيات التخدير، وتقنيات الأشعة والسونار، وتقنيات صناعة الأسنان، وتقنيات صحة المجتمع | الخطط الدراسية الرسمية لكل المراحل والفصول: الاسم العربي والإنكليزي، والساعات النظرية والعملية، والوحدات |
| تقنيات التجميل | المرحلة الأولى بساعات تقديرية معلَّمة بـ«مراجعة» (لا تتوفر خطة رسمية بعد) |

المواد الموجودة تُحدَّث بأسمائها الرسمية وتبقى محاضراتها، والأساتذة يُضافون دون تكرار. لكليات أخرى استخدم **المواد الدراسية ← استيراد المناهج من Excel** (يتوفر نموذج جاهز للتنزيل).
